DESIGN PATTERNS LAB - SIMPLE JAVA VERSION

Requirements: Java 8 or newer. No external libraries.

There are five independent programs:
Task1Runner.java - Strategy + Decorator
Task2Runner.java - Adapter + Proxy
Task3Runner.java - Bridge + Strategy
Task4Runner.java - Adapter + Decorator
Task5Runner.java - Bridge + Proxy

How to run:
1. Open a terminal in this folder.
2. Compile one task, for example:
   javac Task1Runner.java
3. Run it:
   java Task1Runner

Repeat with Task2Runner, Task3Runner, Task4Runner, and Task5Runner.

Each file contains its own main() method and can be run separately.
